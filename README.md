# 解压航线 / Relaxing Flight Routes

## 中文

解压航线 — 飞机沿航线飞行、定时放松的安卓 App。

民航客机沿真实航线飞行，配有定时放松功能、舒缓音乐（贝多芬《月光》钢琴曲、巴赫小提琴／大提琴）与雨声。

### 安装方法

1. 在 Releases 页面下载 APK 文件。
2. 点击下载好的 APK 文件进行安装；如系统提示，请允许安装未知来源应用。
3. 安装完成后，从桌面图标打开「解压航线」即可使用。

## English

Relaxing Flight Routes is a relaxing Android app where a civil airliner flies along real routes, with a timer, calming music (Beethoven Moonlight piano, Bach violin/cello) and rain sounds.

### Installation

1. Download the APK from Releases.
2. Tap the downloaded APK to install it; if prompted, allow installing apps from unknown sources.
3. After installation, open it from the desktop icon.
